Calculadora de Avaliação Física
Um aplicativo web simples e interativo que reúne uma coleção de testes de aptidão física clássicos e definições da área de Educação Física. Ferramenta ideal para estudantes, professores e profissionais da área que desejam realizar cálculos de forma rápida e transparente.

✨ Funcionalidades
O aplicativo inclui calculadoras para os seguintes testes e protocolos:

Testes de Corrida e Caminhada (Distância Fixa)
🚶 Caminhada de 1.200m: Estima o VO₂máx usando tempo, FC, peso, idade e sexo.

🚶‍♀️ Caminhada de 3.000m: Estima o VO₂máx a partir do tempo e velocidade.

🏃 Corrida de 1.000m: Avalia a capacidade aeróbica com base no tempo.

🏃‍♂️ Corrida de 2.400m (Teste de Cooper): Calcula o VO₂máx com base no tempo para percorrer 1,5 milhas.

🏃‍♀️ Corrida de 3.200m (Protocolo de Ribisl & Kachodorian): Usa tempo, idade e peso para uma estimativa completa do VO₂máx.

🚶‍♂️ Caminhada de 4.800m (Teste de Cooper): Classifica a aptidão com base no tempo para percorrer 3 milhas.

Testes de Corrida e Caminhada (Tempo Fixo)
⏱️ Teste de 12 minutos (Andar/Correr - Cooper): Mede a distância máxima percorrida para classificar o VO₂máx.

⏱️ Teste de 15 minutos (Corrida de Balke): Mede a distância máxima percorrida, ideal para pessoas já condicionadas.

Utilitários e Definições
📏 Calculadora de Ritmo: Classifica a atividade (Andar, Trotar, Correr) com base no tempo por km.

🔥 Definição de Kcal: Explica a relação entre consumo de oxigênio e gasto calórico.

⚡ Definição de METs: Detalha o conceito de Equivalente Metabólico da Tarefa.

Recursos Adicionais para cada teste:
📊 Tabela de Cálculo Detalhada: Mostra o passo a passo de como cada resultado foi obtido.

💾 Salvar em .txt: Permite baixar um arquivo de texto com o resumo dos inputs e resultados.

✨ Design Moderno: Interface limpa, agradável e responsiva para uso em desktop ou celular.

💻 Tecnologias Utilizadas
Este projeto foi construído utilizando apenas tecnologias web front-end padrão, tornando-o leve, rápido e sem dependências.

HTML5: Para a estrutura e conteúdo das páginas.

CSS3: Para a estilização completa, design responsivo e visual moderno.

JavaScript (ES6+): Para toda a lógica dos cálculos, renderização dinâmica das páginas e interatividade.
